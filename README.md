# Судоку голосом

Курсовой проект по дисциплине «Клиент-серверные приложения и сетевые технологии» НИТУ МИСИС.

Смартап для виртуальных ассистентов Салют: игра судоку, в которую можно играть голосом, касанием, пультом или с клавиатуры. Говорите «строка 3 столбец 4 цифра 5» — и цифра появится на поле, а ассистент подтвердит ход или предупредит, если цифра уже есть в строке, столбце или квадрате.

**Авторы:** Цыпандина Е.В. (БПМ-24-ПО-2), Махатырова Д.В. (БПМ-24-ПО-1)

- Фронтенд: https://trixlovevg.github.io/sudoku-voice/
- REST API: https://sudoku-voice-api.onrender.com/api/health
- Запуск на устройстве: «Салют, запусти Судоку голосом»

## Состав репозитория

| Каталог | Что внутри |
|---|---|
| `frontend/` | Canvas App: React 18 + `@salutejs/client` |
| `backend/` | REST API: Node.js + Express (генерация головоломок, таблица рекордов) |
| `scenario/` | Голосовое приложение SmartApp Code (`.sc` + JavaScript ES5) |
| `sudoku-scenario.zip` | Тот же сценарий архивом — для импорта в SmartApp Code |
| `.github/workflows/` | Автоматическая публикация фронтенда на GitHub Pages |

## Возможности

- три уровня сложности, у каждой головоломки ровно одно решение;
- ходы голосом в свободной форме: «поставь пятёрку во вторую строку в шестой столбец», «3 4 5»,
  «выбери клетку 2 6» → «семь»;
- подсказка, проверка ошибок, отмена хода, навигация «вверх/вниз/влево/вправо»;
- таймер и таблица рекордов на сервере;
- адаптация под телевизор (SberBox) и телефон.

## Запуск локально

Нужен Node.js 18+.

**1. Сценарий.** SmartApp Studio → создать проект **Code for SmartApp** → Настройки проекта →
Экспорт/Импорт → загрузить `sudoku-scenario.zip` → Сценарии → «Собрать» → Сборки → скопировать webhook.

**2. CanvasApp.** SmartApp Studio → создать **CanvasApp** с названием «Судоку голосом» →
Параметры → тип сценария SmartApp API, внешняя ссылка — webhook из шага 1 → Сохранить.

**3. Backend:**
```
cd backend
npm install
npm test
npm start          # http://localhost:3001
```

**4. Frontend:** скопировать `frontend/.env.sample` в `frontend/.env`, вписать ключ эмулятора
(Studio → Настройки профиля → Настройки сервисов → SmartApp → Эмулятор) и название смартапа:
```
cd frontend
npm install
npm start          # http://localhost:3000
```
Внизу страницы появится панель ассистента. Разрешите микрофон и скажите «лёгкая игра».

## Публикация

- Фронтенд собирается и публикуется на GitHub Pages автоматически при каждом push
  (workflow `deploy-frontend.yml`). Адрес бэкенда задаётся переменной репозитория `API_URL`.
- Бэкенд развёрнут на Render: Root Directory `backend`, Build `npm install`, Start `npm start`.
- Адрес фронтенда указан в Studio → CanvasApp → Параметры → «Хостинг фронтенда».

## API

| Метод | Адрес | Описание |
|---|---|---|
| GET | `/api/health` | Проверка работы сервера |
| GET | `/api/puzzle?difficulty=easy\|medium\|hard` | Новая головоломка |
| POST | `/api/solve` | Решить судоку `{ puzzle }` |
| GET | `/api/scores?difficulty=medium` | Топ-10 рекордов |
| POST | `/api/scores` | Сохранить результат `{ name, difficulty, seconds, hints }` |
